Expense Tracker

A full-stack expense management application designed to help users
record, manage, visualize, and analyze their personal expenses.

Development Approach

**Frontend:** Vibe-coded React + Vite interface
**Backend:** Hand-crafted FastAPI REST API
**Database:** Hand-designed database integration
**Authentication:** JWT-based authentication & authorization
**Data Visualization:** Interactive expense dashboards
**AI Analysis:** Gemini-powered expense analysis
**Anomaly Detection:** Detection of unusual spending patterns
